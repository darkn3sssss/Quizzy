# Quizzy.

Веб-приложение для проведения викторин с индивидуальным темпом прохождения. Ведущий создаёт квиз и открывает комнату, а игроки подключаются по коду и отвечают на вопросы в браузере.

Ответил — переходи дальше. Ждать остальных нужно только после завершения своего квиза. За быстрые правильные ответы начисляется больше баллов.

## Возможности

- **Редактор квизов:** название, вопросы, варианты ответа и отдельный лимит времени для каждого вопроса.
- **Комнаты:** подключение по четырёхзначному коду и запуск игры ведущим.
- **Личный прогресс:** у каждого игрока свой текущий вопрос и таймер.
- **Подсчёт баллов на сервере:** учитываются правильность и время ответа.
- **Защита от повторных запросов:** повторный ответ не начисляет баллы, запоздавший запрос не применяется к следующему вопросу.
- **Результаты:** ведущий видит прогресс участников; после завершения игры отображается итоговый рейтинг.
- **Две темы:** «Графит» и «Рубин». Выбранное оформление сохраняется в браузере.
- **Главное меню:** выбор роли ведущего или игрока и возврат после игры.

## Быстрый старт

Понадобится Go версии, указанной в [go.mod](go.mod), или новее. Сейчас в проекте указана **1.27.1**. Интерфейс работает без Node.js и отдельной сборки; PostgreSQL для текущей реализации не требуется.

Скачай репозиторий и выполни команды **из его корневой папки**:

```bash
go mod download
go run ./cmd/server
```

Открой [http://localhost:8080](http://localhost:8080).

| Страница | Адрес |
| --- | --- |
| Главное меню | `http://localhost:8080/` |
| Ведущий | `http://localhost:8080/host.html` |
| Игрок | `http://localhost:8080/player.html` |

Проверка доступности сервера:

```bash
curl http://localhost:8080/health
```

Ответ: `{"status":"ok"}`.

Порт `8080` задан в [cmd/server/main.go](cmd/server/main.go). Запуск из корня нужен, чтобы сервер нашёл файлы интерфейса в `web/static`.

### Игра с других устройств

Подключи устройства к одной локальной сети. На телефоне или другом компьютере открой `http://<IP-компьютера-с-сервером>:8080`, затем выбери роль игрока. Компьютер с сервером должен разрешать входящие подключения на порт `8080`.

`localhost` на телефоне указывает на сам телефон, поэтому для подключения нужен локальный IP компьютера, где запущен Quizzy.

## Как провести квиз

1. Открой меню и выбери **«Я ведущий»**.
2. Создай квиз: добавь вопросы, варианты, отметь правильные ответы и задай время. В редакторе доступен лимит от 5 до 300 секунд на вопрос.
3. Выбери сохранённый квиз и создай комнату.
4. Передай участникам адрес сайта и код комнаты.
5. Игроки выбирают **«Я игрок»**, вводят код и имя. Присоединиться можно до начала игры.
6. Запусти игру. Каждый участник проходит вопросы самостоятельно, а ведущий наблюдает за прогрессом.
7. После завершения всеми участниками появляется итоговый рейтинг. Крестик на экране завершения возвращает в меню.

Для проверки на одном компьютере открой ведущего и игроков в разных вкладках.

## Как начисляются баллы

Для обычного игрока за правильный ответ:

```text
баллы = round(10 × (лимит − прошедшее время) / лимит) × 10
```

Время учитывает сервер в целых секундах. Например, при лимите 30 секунд правильный ответ через 0 секунд даёт 100 баллов, через 15 секунд — 50, а на границе 30 секунд — 0. Неправильный ответ не приносит баллов; после истечения лимита сервер отклоняет ответ.

В текущем коде для имён `Cheater`, `Admin` и `Semen` предусмотрен специальный множитель: `10000` вместо `10`. Эта особенность реализована в [answer_handler.go](internal/handlers/answer_handler.go).

## Устройство проекта

Сервер написан на Go с использованием `net/http`. Интерфейс — HTML, CSS и JavaScript без фронтенд-фреймворка. Браузер обменивается с сервером JSON-запросами и периодически получает состояние игры по HTTP.

```text
Quizzy/
├── cmd/server/main.go          # Запуск сервера и маршруты
├── internal/
│   ├── handlers/              # Обработка квизов, комнат и ответов
│   ├── models/                # Модели данных и форматы запросов
│   └── storage/               # Интерфейс хранилища и реализация в памяти
├── web/static/
│   ├── index.html             # Главное меню
│   ├── host.html              # Интерфейс ведущего и редактор
│   ├── player.html            # Интерфейс игрока
│   ├── menu.css               # Оформление меню
│   ├── theme.css              # Общие темы оформления
│   └── theme.js               # Переключение и сохранение темы
├── go.mod
└── go.sum
```

Состояние комнат обновляется под `sync.RWMutex`. Индекс вопроса в запросах позволяет серверу отличать текущие действия от запоздавших повторов.

## HTTP API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/health` | Проверка доступности |
| `GET` | `/quizzes` | Список квизов |
| `GET` | `/quiz/{id}` | Получение квиза |
| `POST` | `/quiz` | Создание квиза |
| `POST` | `/rooms` | Создание комнаты по `quiz_id` |
| `POST` | `/rooms/{code}/join` | Подключение по имени `name` |
| `POST` | `/rooms/{code}/start` | Запуск игры |
| `GET` | `/rooms/{code}/state` | Статус комнаты и участники |
| `GET` | `/rooms/{code}/state/{id}` | Вопрос, таймер и состояние игрока |
| `POST` | `/rooms/{code}/next/{id}` | Переход игрока к следующему вопросу |
| `POST` | `/rooms/{code}/answer` | Отправка ответа |

Тела запросов передаются как JSON с заголовком `Content-Type: application/json`. Для ответа нужны `player_id`, `question_index` и `option`. Для перехода — `question_index` текущего вопроса; перед первым вопросом его значение равно `-1`. Нумерация вопросов и вариантов начинается с `0`.

## Текущий статус

Quizzy — учебный проект. Квизы, комнаты и результаты хранятся в памяти и исчезают после перезапуска сервера. Хотя в зависимостях присутствует `pgx`, подключение к PostgreSQL пока не используется.

Авторизация ведущего, постоянное хранение данных и автоматическая обработка выбывших участников пока не реализованы. Комната завершается, когда все присоединившиеся игроки закончат квиз; отключившийся участник может оставить её активной.
